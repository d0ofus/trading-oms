# Product Quality Rubric

Score each slice against:

1. Trading safety.
2. Auditability.
3. Determinism.
4. Test coverage.
5. Clear state transitions.
6. Secret hygiene.
7. Broker isolation.
8. Simplicity.
9. Documentation.
10. Operability.

Any slice with a live-trading path, secret leakage, or risk bypass fails automatically.
