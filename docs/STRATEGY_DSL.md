# Strategy DSL

The strategy DSL will be a typed JSON/YAML representation of strategy workflows.

## Requirements

- Deterministic.
- Versioned.
- Validated before execution.
- No arbitrary code execution.
- Replay-compatible.
- UI-compatible.
- Auditable.

## Initial status

Not implemented.

The first replay-only strategy is hard-coded and documented in `docs/REPLAY_STRATEGY.md`.

The full DSL remains deferred.
