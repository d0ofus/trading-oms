# Strategy DSL

The strategy DSL will be a typed JSON/YAML representation of strategy workflows.

## Requirements

- Deterministic.
- Versioned.
- Validated before execution.
- No arbitrary code execution.
- Replay-compatible.
- UI-compatible.
- Auditable.

## Initial status

Not implemented.

The first strategy should be hard-coded or config-driven before the full DSL is introduced.
