# Incident Response

## Critical incidents

- Unexpected order.
- Duplicate order.
- Position without expected protection.
- Unknown broker state.
- Stale data used for decision.
- Missing audit event.
- Secret leakage.
- IBKR port exposure.
- Reconciliation failure.

## Initial response

1. Stop new risk-increasing decisions.
2. Preserve logs and event journal.
3. Alert operator.
4. Reconcile orders and positions.
5. Document timeline.
6. Fix root cause.
7. Add regression tests.
